# AI-Powered Proctored Exam Platform

## Overview
This project is a full-stack platform for secure, privacy-conscious, AI-driven online proctored exams. It covers pre-exam verification, live monitoring, intelligent flagging, and post-exam audit/reporting.

### Main Components
- **frontend/**: React app for candidate/institution interface
- **backend/**: Node.js/Express API for exam logic, user management, and orchestration
- **ai-services/**: Python microservices for face recognition, anomaly detection, audio analysis, and risk scoring
- **database/**: MongoDB (or similar) for persistent storage

### Features
- Pre-exam verification: Face recognition, ID validation, environment scan
- Live monitoring: Detect tab switching, multiple faces, eye movement, audio cues, unauthorized devices
- Intelligent flagging: AI-driven risk scoring, false positive reduction
- Post-exam audit: Auto-generated proctoring report with timestamped evidence
